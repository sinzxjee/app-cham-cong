# App Chấm Công

Web app chấm công tối ưu cho điện thoại.

## Tính năng

- Nhập ngày, giờ vào và giờ ra
- Tự tính ca qua đêm
- Phụ cấp ca đêm 22:00–02:00 mặc định 30%
- Ô tích lễ/Tết để tính lương 300%
- Tùy chỉnh lương giờ, thời gian nghỉ và hệ số
- Lưu dữ liệu trên trình duyệt
- Xuất dữ liệu CSV

Mở `index.html` hoặc triển khai bằng GitHub Pages/static hosting.
